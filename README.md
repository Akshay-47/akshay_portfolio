# Akshay Kumar LR - Portfolio Website

Personal portfolio website built and maintained by Akshay Kumar LR.

## Live Site

- [https://akshay-47.github.io/akshay_portfolio/](https://akshay-47.github.io/akshay_portfolio/)

## Tech Stack

- React
- Sass
- JavaScript

## Local Development

```bash
npm install
npm start
```

## Production Build

```bash
npm run build
```

## Deployment

This project is configured for GitHub Pages.

```bash
npm run deploy
```

## Project Structure

- `src/portfolio.js`: Primary content and section configuration
- `src/containers/`: Section-level React containers
- `src/components/`: Reusable UI components
- `public/`: Static assets and app metadata
